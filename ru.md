# Система наказания за нарушение
На нашем сервере действует система из двух предупреждений: 
- **Тайм-аут** - лёгкое и первое предупреждение. Временное ограничение возможности писать на сервере ("время подумать");
- **Выговор** (<@&1468583381104197703>) - полноценное и второе предупреждение. Может также сопровождаться временным ограничением возможности писать на сервере. Предупреждение фиксируется за пользователем в виде роли, которую нельзя снять повторным входом на сервер: специальный бот автоматически вернёт её. Срок её действия - ровно 2 недели. По истечении этого срока предупреждение аннулируется, и процесс начинается заново.

При повторном нарушении после получения двух предупреждений, следует блокировка:
- **Ограничение доступа** (<@&962822879173546116>) - форма блокировки, при которой пользователю выдаётся специальная роль, полностью лишающая возможности взаимодействовать с сервером. Пользователь сможет только читать сообщения. Единтсвенное исключение - канал аппеляций блокировок (<#>). Эту роль также нельзя снять повторным входом на сервер: специальный бот автоматически вернёт её. Блокировка бессрочная; единственный способ снять её - подать апелляцию модерации или администрации.

Эта система применяется не ко всем правилам. В незначительных случаях модерация или администрация может ограничиться устным предупреждением, а в более серьёзных - сразу применить блокировку, минуя этап предупреждений. Некоторые исключения отдельно указаны в правилах.

# Апелляция блокировки
Апелляции на блокировку рассматриваются индивидуально и решение по ним принимается по нашему усмотрению.
Апелляция может быть рассмотрена при следующих условиях:
1. С момента блокировки прошло более 2 недель.
2. Блокировка была выдана не за целенаправленное вредительство серверу (например "рейды").
3. Не было попыток обойти блокировку с использованием альтернативного аккаунта.
4. Ранее блокировка не снималась с пользователя через апелляцию.
Чтобы подать апелляцию на снятие блокировки, обратитесь в канал аппеляций блокировок (<#>) или напрямую к одному из администраторов сервера.
После снятия блокировки по апелляции Вам будет выдана роль **На испытательном сроке** (роль <@&> probation), которая равнозначна предупреждению **Выговор** (<@&1468583381104197703>). Срок её действия - ровно 2 недели.
